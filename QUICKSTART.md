# Quick Start Guide

## Installation (One Time)

```bash
# Install dependencies
pip install -r requirements.txt
```

## Running the Application

```bash
python air_drums.py
```

## What You Need

1. **A GREEN object** - Green marker, green paper, green pen, anything bright green
2. **Your webcam** - Make sure it's working
3. **Good lighting** - Natural or bright light works best

## How to Play

1. **Start the app** - Run `python air_drums.py`
2. **Read the instructions** - The landing page will show you everything
3. **Hold your green object** - In one or both hands
4. **Move up and down** - Like you're hitting drums!
5. **Hit different zones**:
   - **Top row**: Kick, Snare, Tom
   - **Bottom row**: Floor, Hi-Hat, Ride

## Tips

- Hit harder = louder sound
- Stay 2-4 feet from camera
- Use a solid green color (not transparent)
- Avoid green backgrounds
- Press 'Q' to quit

## Troubleshooting

**No green object detected?**
- Check lighting
- Try a brighter green
- Adjust color settings in `config.json`

**No sound?**
- Check system volume
- Verify audio files exist in `audio/` folders

**Camera not working?**
- Close other apps using camera
- Try changing camera index in `config.json`

That's it! Have fun making music! 🥁
